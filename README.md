# letter-site

jeslyn's personal website — a minimal, static site.

## pages
- `index.html` — about
- `things-i-like.html` — a pinterest-style board of interests
- `read-a-book.html` — placeholder (coming soon)

## run locally
open `index.html` in a browser, or serve the folder:

```
python3 -m http.server
```

## design
- background `#f4f3ee`, black text, accent `#5b2a55`
- inter sans-serif, everything lowercase
- shared styles in `styles.css`
